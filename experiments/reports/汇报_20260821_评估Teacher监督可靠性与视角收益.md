# 评估 Teacher 监督可靠性与视角收益：实验汇报

> **评测对象**：Qwen3.5-VL-4B Frozen Teacher  
> **实验目的**：测量 Teacher 监督正确性、回答形态及视角数量的独立影响  
> **评测规模**：124,306 条训练样本 + 40,000 条受控视角扫描样本  
> **实验编号**：`20260820_teacher_reliability`  
> **结果目录**：`logs/eval/teacher_reliability/{as_trained,sweep_vlm3r,sweep_spar32}/`

## 摘要

Qwen3.5-VL-4B Teacher 在完整训练池上的总体正确率为 **41.4%**，作答率为 **97.6%**。
该总体分数包含本项目内部定义的 BEV 坐标评分；去除 BEV 后，正确率为 **42.1%**。
可靠性高度依赖题型：描述类与部分距离类任务可达到 55%–58%，而最难的
32 视角物体间空间想象任务仅为 1.3%–1.5%。

受控实验进一步表明，增加视角只能带来有限收益：

- 在 `vlm3r` 上，正确率由 1 视角的 33.0% 提升至 5 视角的 42.1%，此后不再稳定增长；
- 在 `spar32` 上，正确率由 1 视角的 11.9% 提升至 32 视角的 22.0%，
  其中 16 视角以后增益已明显趋缓。

因此，在高视角预算区间，当前 Teacher 的主要瓶颈不是输入视角不足，
而是任务相关的推理能力与回答完整性。
从监督质量和计算成本综合考虑，**不建议对所有样本统一使用 32 个视角**；
更合理的方案是以 8 个视角为基础预算，并对明确依赖特定帧的样本按需补充视角。

### 核心结论与建议

1. **视角收益呈明显边际递减**：`vlm3r` 在 5 视角后趋于饱和，`spar32` 在 16 视角后趋缓；
   8→32 视角的额外收益有限，与新增计算成本不成比例。
2. **监督质量存在显著题型差异**：不同题型正确率相差 40 倍以上，不宜以相同权重参与蒸馏。
3. **空间想象题主要受回答不完整影响**：Teacher 经常只输出一个空间轴，而金标要求同时覆盖多个轴。
   应先优化提示词并复测，再决定是否纳入蒸馏。

## 一、实验目的与研究问题

### 1.1 实验背景

MV-OPSD 使用特权视角 Teacher 的 next-token 分布监督 Student。训练目标
`vopd_loss` 衡量的是二者在 Student response 上的分布差异，而不是 Teacher
给出的答案是否正确。因此，即使蒸馏损失稳定下降，也可能出现以下情况：

```text
Student 更接近 Teacher，但 Teacher 本身答错、答不完整或输出冗长推理，
最终导致下游任务能力下降。
```

此前训练已观察到：VOPD loss 可以持续收敛，但 VSI-Bench 与 CV-Bench 性能下降。
为判断问题来自优化过程还是监督源质量，本实验直接测量 Frozen Teacher
在实际训练输入上的可靠性。

### 1.2 实验目的

本实验解决三个相互关联但需要分开回答的问题：

1. **监督正确性**：Teacher 在完整训练池上的总体正确率是多少？不同数据源和题型之间是否存在显著差异？
2. **视角收益**：增加 Teacher 视角是否稳定提高正确率？收益在多少视角后开始饱和？
3. **回答质量**：低分究竟来自空间判断错误、回答不完整，还是生成格式与评分协议不匹配？

这些问题分别决定后续训练中的三类选择：

- 哪些数据适合直接参与蒸馏；
- Teacher 应使用多少视角；
- 是否需要修改 Teacher prompt、样本权重或评分方法。

### 1.3 研究假设

实验不预设 Teacher 必然可靠，重点检验以下假设：

- 若信息量是主要瓶颈，正确率应随视角数持续上升；
- 若推理能力或回答协议是主要瓶颈，增加视角后的收益会快速饱和；
- 若不同题型可靠性差异很大，统一样本权重会让错误监督与正确监督等权进入训练；
- 若方向题主要是“没有答全”，严格全匹配分数会低估 Teacher 在已输出空间轴上的判断能力。

## 二、实验设置

### 2.1 评测对象与数据构成

本评测直接读取 rollout8 训练所用的
`data/mvopsd/parquet/main_train.parquet`，并按 `n_views_teacher` 统计。
Teacher 在实际训练中只使用过以下 7 种视角数：

| N | 行数 | 来源构成 |
|---|---|---|
| 3 | 33,970 | 全部 spar_3view |
| 4 | 351 | llava_hound（视频帧数 4-8 浮动） |
| 5 | 1,531 | llava_hound |
| 6 | 3,805 | llava_hound |
| 7 | 1,429 | llava_hound |
| 8 | 62,695 | vlm3r_scannet + llava_hound |
| 32 | 20,525 | 全部 spar_32view |

需要特别注意：视角数与数据源高度相关。例如，3 视角样本全部来自 `spar_3view`，
32 视角样本全部来自 `spar_32view`。因此，该自然分布只能用于描述训练数据，
不能直接用于估计视角数的因果效应。

### 2.2 推理协议

为确保评测与训练阶段一致，推理过程直接复用了 `teacher_prompt` 和 `teacher_images`，
且保持以下设置不变：

- 不添加 system message；
- `enable_thinking=False`；
- 不额外覆盖 `min_pixels` / `max_pixels`；
- 最大上下文长度为 12,288 tokens；
- 最大输出长度为 1,024 tokens。

### 2.3 指标口径

- **正确率**：所有样本得分之和除以样本数；未能判读或未给出有效答案的样本计 0 分。
  多项选择、方向和比较题采用 0/1 得分，数值题采用与 VSI-Bench 一致的 MRA 分数。
- **作答率**：能够从 Teacher 输出中提取出可评分答案的样本比例。
- 除特别说明外，本文表格均报告全样本口径，而不是仅在已作答样本上统计。

### 2.4 两阶段评分流程

不同数据集的金标形式并不统一：既有选项字母、裸数值，也有多轴方向描述和开放式视频摘要。
因此，评测采用“**确定性规则优先，LLM 仅作必要补充**”的两阶段流程：

1. 规则层根据题型提取选项、数值、方向轴或对象名称，并按固定指标评分；
2. 仅当规则无法提取回答时，才调用 `gpt-oss-120b`；
3. 除开放式 `llava_hound` 外，LLM 只负责抽取 Teacher 实际表达的答案，
   最终正确性仍由精确匹配、MRA 或全轴匹配规则决定；
4. `llava_hound` 没有唯一结构化答案，因此使用 LLM 进行语义一致性判断，并单独校准。

这种设计避免让 LLM judge 的主观标准替代数据集原有指标。

## 三、实验结果：完整训练池

### 3.1 总体结果

在 124,306 条实际训练样本上，Teacher 的总体正确率为 **41.4%**，作答率为 **97.6%**。
去除采用本项目内部 BEV 坐标容差评分的 2,436 条样本后，其余样本正确率为 **42.1%**。

该结果说明 Teacher 通常能够产生可解析回答，但“能够作答”不等于“回答正确”：
作答率接近 98%，正确率仍只有约 41%。

### 3.2 按实际视角数统计

| Teacher 视角数 | 样本数 | 正确率 | 作答率 |
|---|---|---|---|
| 3 | 33,970 | 33.4% | 94.9% |
| 4 | 351 | 47.8% | 98.0% |
| 5 | 1,531 | 59.8% | 100.0% |
| 6 | 3,805 | 58.9% | 100.0% |
| 7 | 1,429 | 58.8% | 99.9% |
| 8 | 62,695 | 50.9% | 99.1% |
| 32 | 20,525 | 19.9% | 96.8% |

> **解读限制**：该表同时反映视角数和数据源差异，不能据此得出“视角越多，准确率越低”的结论。
> 例如，32 视角样本全部来自难度较高的 SPAR 任务，而 5–7 视角样本主要来自
> `llava_hound` 描述任务。视角数的独立影响应以第四节的受控扫描为准。

### 3.3 按数据源统计

| 数据源 | 样本数 | 正确率 |
|---|---|---|
| llava_hound_64k | 37,509 | 57.7% |
| vsi_appr_order | 1,735 | 55.3% |
| vlm3r_scannet | 30,567 | 44.0% |
| spar_3view | 33,970 | 33.4% |
| spar_32view | 20,525 | 19.9% |

不同数据源之间存在显著差异：`llava_hound_64k` 的正确率最高，为 57.7%；
`spar_32view` 最低，为 19.9%。这进一步说明，训练池中的视角数统计受到任务构成的强烈影响。

### 3.4 按题型统计

| 数据源 / 题型 | 样本数 | 正确率 |
|---|---|---|
| llava_hound / 描述题 | 37,509 | 57.7% |
| spar_3view / distance_infer_center_oo | 4,985 | 57.0% |
| vsi_appr_order / appearance_order | 1,735 | 55.3% |
| spar_3view / distance_prediction_oc | 5,406 | 46.8% |
| spar_3view / depth_prediction_oc | 5,454 | 44.7% |
| vlm3r_scannet / 主体任务 | 30,495 | 44.1% |
| spar_32view / obj_count | 2,799 | 39.1% |
| spar_32view / distance_prediction_oo | 3,970 | 35.1% |
| spar_32view / room_size | 787 | 30.0% |
| spar_3view / distance_prediction_oo | 5,551 | 27.8% |
| spar_3view / obj_spatial_relation_oc | 4,869 | 23.1% |
| spar_3view / obj_spatial_relation_oo | 2,338 | 16.0% |
| spar_32view / spatial_imagination_oc | 3,270 | 14.5% |
| spar_3view / spatial_imagination_oc | 2,271 | 12.5% |
| spar_3view / spatial_imagination_map（BEV） | 2,436 | 6.1% |
| **spar_32view / spatial_imagination_oo** | 3,162 | **1.3%** |
| **spar_32view / spatial_imagination_oo_hard** | 2,568 | **1.5%** |

题型正确率从 57.7% 到 1.3%，相差 40 倍以上。该结果表明，使用统一权重进行蒸馏会使
高质量和低质量监督信号被等量处理，存在明显风险。

### 3.5 空间方向题：区分“回答不完整”与“方向判断错误”

`spatial_imagination_oo_video` 在全样本口径下的严格全匹配正确率仅为 1.3%。
该指标要求 Teacher 同时正确回答金标涉及的全部空间轴（左右、上下、远近）；
只回答其中一部分，即使已回答的方向正确，也记为 0 分。

为明确低分来源，针对**规则层能够判读的方向回答**进一步统计：

- **回答完整率**：在可判读方向回答中，覆盖全部金标轴的比例；
- **已输出轴准确率**：仅在 Teacher 实际输出的轴上计算微平均准确率；
- **严格全匹配率**：在可判读方向回答中，所有金标轴均正确的比例。

| 数据源 / 题型 | 回答完整率（可判读回答内） | 已输出轴准确率 | 严格全匹配率（可判读回答内） |
|---|---|---|---|
| spar_32view / spatial_imagination_oo_video | **2.9%** | 68.2% | 1.6% |
| spar_32view / spatial_imagination_oo_video_hard | 2.8% | 69.1% | 2.1% |
| spar_32view / spatial_imagination_oc_video | 36.2% | 55.3% | 17.7% |
| spar_3view / obj_spatial_relation_oc_mv | 32.6% | 73.0% | 24.9% |
| spar_3view / obj_spatial_relation_oo_mv | 9.5% | 73.6% | 17.4% |
| spar_3view / spatial_imagination_oc_mv | 30.2% | 51.1% | 14.8% |

表中的严格全匹配率仅在规则层可判读回答内计算，因此与 3.4 节报告的全样本正确率口径不同。

结果显示，`spatial_imagination_oo_*` 的主要问题是**回答不完整**：
在规则层可判读的回答中，完整率不足 3%，而已输出轴上的条件准确率约为 68%–69%。
这并不能证明未输出轴也能被正确判断，但说明低分不能简单归因于方向识别能力不足。
更直接的改进方式是通过提示词明确要求逐轴输出，再使用同一评测协议复测。

## 四、实验结果：受控视角扫描

为消除数据源和题型差异的干扰，受控实验固定题目与相册，仅改变 Teacher 接收的视角数。
每个预算下均从完整相册中**按时间顺序等间隔取样**，以保证覆盖范围可比。

### 4.1 `vlm3r` 扫描

实验规模为 2,500 道题 × 8 种视角预算，共 20,000 条评测样本。

| 视角数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 正确率 | 33.0% | 35.5% | 36.9% | 39.5% | **42.1%** | 41.2% | 42.3% | 41.4% |

从 1 个视角增加到 5 个视角，正确率提高 9.1 个百分点；继续增加至 8 个视角后，
结果始终处于 41.2%–42.3% 区间，未观察到稳定的进一步提升。

### 4.2 `spar32` 扫描

实验选取 2,000 道不引用特定帧的题目（`required_views == 0`），
设置 10 种视角预算，共 20,000 条评测样本。
该筛选可避免减少视角后题目仍引用缺失帧，从而改变原始题意。

| 视角数 | 1 | 2 | 3 | 4 | 6 | 8 | 12 | 16 | 24 | 32 |
|---|---|---|---|---|---|---|---|---|---|---|
| 正确率 | 11.9% | 12.8% | 13.0% | 14.9% | 16.5% | 18.4% | 19.8% | 20.7% | 20.5% | **22.0%** |

从 1 个视角增加到 32 个视角，正确率提高 10.0 个百分点。
16、24 和 32 视角的结果分别为 20.7%、20.5% 和 22.0%，表明 16 视角后边际收益已较小。
同时，即使提供全部 32 个视角，正确率仍仅为 22.0%，说明增加视觉信息无法解决该任务的主要困难。

### 4.3 受控扫描的直接观察

- **边际收益持续下降**：`vlm3r` 在 5 视角后趋于饱和；`spar32` 仍可受益至约 16 视角，
  但此后继续增加视角的收益较小。
- **增加视角不能替代推理能力**：`spar32` 在 32 视角下仍只有 22.0%。
- **应采用自适应视角预算**：对于不引用特定帧的样本，8 视角是更合理的基础预算；
  对题面明确依赖特定帧的样本，应至少保留所需视角。现有结果不支持对所有样本统一使用 32 视角，
  因为这会显著增加视觉 token、显存和推理时间，而监督质量提升有限。

## 五、实验结果分析

### 5.1 Teacher 可靠性主要由任务类型决定，而不是由视角数单独决定

自然训练池中，5–7 视角的正确率约为 59%，32 视角仅约 20%。这一现象不能解释为
“视角越多，模型越差”，因为视角数与数据源高度绑定：

- 5–7 视角几乎全部来自较容易的 `llava_hound`；
- 32 视角全部来自更困难的 `spar_32view`；
- 3 视角全部来自 `spar_3view`。

真正控制题目和数据源后，增加视角仍能提高准确率，但收益明显小于自然分组表看起来的差异。
因此，**任务定义、答案协议和推理难度是主变量，视角数只是其中一个辅助变量。**

### 5.2 视角收益存在明显边际递减

`vlm3r` 从 1 视角增加到 5 视角提升 9.1 个百分点，但 5–8 视角始终在
41.2%–42.3% 之间波动，没有稳定上升趋势。

`spar32` 从 1 视角增加到 16 视角仍有收益，但 16 / 24 / 32 视角仅为
20.7% / 20.5% / 22.0%。将视觉输入从 16 张扩大到 32 张，计算量显著增加，
准确率只提升约 1.3 个百分点。

这说明：

- 低视角区间主要受可见信息不足影响；
- 高视角区间主要受空间推理与回答协议限制；
- 统一使用 32 视角不是成本有效的默认方案。

### 5.3 近零方向题分数主要反映回答完整性，而不是完全缺乏方向感

`spatial_imagination_oo_video` 的全样本严格正确率只有 1.3%，表面上低于三轴随机猜测的
12.5%。分解后可以看到：

- Teacher 答全金标要求的全部空间轴的比例仅为 2.9%；
- 但在它主动输出的空间轴上，准确率达到 68.2%；
- hard 版本对应数字为 2.8% 与 69.1%。

因此，主要错误模式是 Teacher 只回答“above”或“left”等单一关系，
而金标要求同时给出左右、上下、远近三个轴。严格全匹配按协议将其记为 0，
但这不等于已输出的方向判断完全错误。

该结果的训练含义是：应先通过 prompt 强制逐轴完整输出，再评估其是否适合蒸馏；
直接将 1.3% 理解为“Teacher 没有空间方向能力”会导致错误决策。

### 5.4 Teacher 的长回答形态可能向 Student 传递非任务性风格

600 条随机冒烟样本显示，Teacher 输出中位长度约为 **215 token**，最长达到 1,024 token；
即使 `vlm3r` prompt 明确要求直接输出选项字母，Teacher 通常仍先写长篇分析。
作为对照，同一基座在带 system message 的 VSI-Bench 协议下，中位输出只有约 4 token。

VOPD 会在 Student 自己的整段 response 上对齐 Teacher 的 next-token 分布。
因此，即使 Teacher 最终答案正确，长篇分析、逐帧枚举与回答不收束也可能作为软目标传给 Student。

这与后续训练观察到的 Student 回答变长、逐帧重复和 VSI-Bench 退化方向一致。
不过，本实验只测量了 Teacher 的回答形态，没有进行“短答 Teacher vs 长答 Teacher”的训练对照，
所以该联系应视为**有证据支持的机制假设**，而不是已经建立的因果结论。

### 5.5 统一样本权重会混合质量差异极大的监督信号

题型正确率从 57.7% 跨越到 1.3%，相差 40 倍以上。若所有 response token 使用相同权重：

- 高可靠性描述题与低可靠性空间想象题对优化目标具有同等资格；
- 长回答样本还会因 `token-mean` 聚合贡献更多 token；
- 蒸馏损失下降只能说明 Student 更接近混合 Teacher 分布，不能证明空间能力改善。

因此，后续训练应将**监督可靠性、回答长度和题型**同时纳入采样或损失权重设计，
而不是只按数据行数构建训练池。

### 5.6 对原研究问题的回答

| 研究问题 | 实验回答 |
|---|---|
| Teacher 是否足够可靠，可无差别用于蒸馏？ | 否。总体约 41%，题型差异超过 40 倍 |
| 更多视角是否持续改善 Teacher？ | 否。`vlm3r` 约 5 视角后饱和，`spar32` 约 16 视角后趋缓 |
| `spar32` 低分是否主要因为视角不足？ | 否。32 视角仍只有约 22%，高预算区间瓶颈不在信息量 |
| 空间想象题是否完全没有方向判断能力？ | 不能这样解释；主要问题是回答不完整 |
| 当前 Teacher 输出是否可能造成 Student 风格漂移？ | 存在明显风险，但仍需训练消融验证因果关系 |

## 六、评分方法与结果可信度

### 6.1 统一评分流程

评测采用“**规则解析优先，LLM 仅作必要补充**”的两级流程：

1. 先根据数据源、金标格式和 `question_type` 确定答案类型；
2. 使用确定性规则分别解析金标和 Teacher 回答；
3. 若规则能够明确提取回答，则直接按该题型的固定指标评分；
4. 若金标可解析、但规则无法从回答中提取答案，则将该样本送入 `gpt-oss-120b`；
5. 除 `llava_hound` 外，LLM 只负责**提取 Teacher 实际表达的答案**，不直接判断对错。
   提取结果仍交回原题型的规则指标评分。

该设计避免使用 LLM 的主观标准替代数据集原有的答案定义。完整训练池中，
规则层直接完成了 78,177 / 124,306 条样本的评分，占 **62.9%**；
其余 46,129 条进入 LLM 辅助层，其中 43,977 条成功获得可评分答案，
2,152 条仍未能提取出有效答案，按协议计为 0 分。

### 6.2 各数据集的具体评分方法

| 数据集 | 金标形式 | 首选评分方法 | 规则无法判读时的处理 |
|---|---|---|---|
| `llava_hound_64k` | 开放式自然语言描述 | LLM 语义一致性判断 | 全部样本直接进入语义判断，无规则评分层 |
| `vlm3r_scannet` | 选项字母或裸数值 | 选择题精确匹配；数值题 MRA | LLM 只提取选项或最终数值，再按同一指标评分 |
| `vsi_appr_order` | 选项字母 | 选项精确匹配 | LLM 只提取选项字母，再做精确匹配 |
| `spar_3view` | 模板化自然语言 | 按题型解析为数值、方向、比较、BEV 或 Yes/No | 数值、方向、比较、Yes/No 可进入提取模式；BEV 不使用 LLM 补判 |
| `spar_32view` | 模板化自然语言 | 与 `spar_3view` 相同 | 与 `spar_3view` 相同 |

两条受控扫描不引入新的评分口径：`sweep_vlm3r` 完全复用
`vlm3r_scannet` 的评分方法，`sweep_spar32` 完全复用 `spar_32view` 的评分方法。

#### `llava_hound_64k`

该数据集的金标是开放式场景描述，不存在唯一的选项、数值或结构化答案，因此不能使用精确匹配。
每条样本都向 `gpt-oss-120b` 提供问题、参考描述和 Teacher 回答，由其输出 Yes/No，
判断 Teacher 回答是否与参考答案在语义上相符。Yes 记 1 分，No 记 0 分；
无法解析判定结果时记为未作答并计 0 分。

这是本评测中唯一让 LLM 直接给出正确性判断的数据集。因此，针对该分支单独设置了校准探针：

- 正例：将参考答案本身作为 Teacher 回答，共 100 条，全部被判为正确；
- 负例：将其他随机样本的参考描述替换为当前回答，共 100 条，1 条被误判为正确。

该结果说明语义判断分支在校准样本上具有较高区分度，但 1% 的负例误接受率也表明，
57.7% 的 `llava_hound` 得分应视为 LLM 语义口径下的估计，而非精确匹配意义上的绝对准确率。

#### `vlm3r_scannet`

`vlm3r_scannet` 包含两类金标：

- **选择题**：从 Teacher 长回答中依次查找显式结论、末行选项字母，或唯一匹配的选项文本；
  提取结果必须属于题面实际提供的选项集合。与金标字母一致记 1 分，否则记 0 分。
- **数值题**：优先提取带有 `answer`、`result`、`distance`、`count` 等结论标记的最终数值，
  否则读取最后一个包含有效数字的回答行。提取值使用 MRA 评分。

MRA 使用 0.50–0.95、步长 0.05 的 10 个相对误差阈值。
预测误差不超过 5% 时得 1.0 分，不超过 10% 时得 0.9 分，
仅满足 50% 误差阈值时得 0.1 分，误差超过 50% 时得 0 分。

如果规则层无法提取选项或数值，LLM 只返回一个选项字母或一个最终数字，
随后仍使用精确匹配或 MRA 评分。`sweep_vlm3r` 的反向抽查中，
规则层与 LLM 提取结果的评分分歧率为 **0.51%（2/391）**。

#### `vsi_appr_order`

该数据集的金标为选项字母。评分器从回答结论或最后一行提取选项，
并将候选字母限制在题面实际提供的选项范围内；如果 Teacher 只写出选项文本，
仅在该文本能唯一对应某一选项时才接受。最终采用字母精确匹配，正确记 1 分，错误记 0 分。

规则无法提取时，LLM 仅负责返回 Teacher 所选择的字母，再进行同样的精确匹配。
本数据集未单独进行分层反向抽查，其规则评分可靠性由完整训练池的综合反向抽查覆盖。

#### `spar_3view` 与 `spar_32view`

两个 SPAR 数据集采用相同评分器。模板化金标先被转换为五类结构化答案，
另对部分 Yes/No 题单独处理：

| 答案族 | 典型题型 | 评分规则 | LLM 补判条件 |
|---|---|---|---|
| 数值 | 深度、距离、物体计数、房间面积 | 提取数值后使用 MRA；带米或平方米单位的数值优先于物体编号、帧号 | 规则未提取出数值时，由 LLM 只返回最终数字 |
| 方向 | 物体空间关系、视角变换后关系 | 水平、垂直及适用时的深度轴必须全部与金标一致，才得 1 分 | 完全未提取到任何方向轴时，LLM 按轴输出；只回答部分轴属于可判读但不完整，直接记 0 分 |
| 两对象比较 | 绿色点与蓝色点谁更近或更远 | 归一化 `closer/farther` 极性后，比较最终对象是否一致 | 规则未提取出对象时，由 LLM 只返回题面中的对象 |
| 多对象比较 | 多个 `ObjectN` 中谁最近或最远 | 统一 `ObjectN`、`pointN` 和题面对象名后做精确匹配 | 规则未提取出对象时，由 LLM 只返回题面中的对象 |
| BEV | 鸟瞰坐标预测 | 每个对象预测点距金标不超过 0.5 m 视为命中；得分为命中对象数 / 金标对象总数 | 不使用 LLM 补判 |
| Yes/No | 部分物体关系题 | 提取最终 Yes 或 No 后精确匹配 | 规则未提取时，由 LLM 只返回 Yes 或 No |

方向题采用严格全轴匹配：例如金标为“left + above + farther”，回答只给出“left + above”
时，虽然已输出的两个轴都正确，仍按不完整答案记 0 分，而不是送给 LLM 猜测缺失轴。
这也是 3.5 节同时报告回答完整率和已输出轴准确率的原因。

BEV 的 0.5 m 容差是本项目内部定义，并非 SPAR 官方指标。因此，BEV 得分适合用于本实验内部比较，
不应直接与外部 SPAR 结果比较。本文 41.4% 的总体正确率包含该内部 BEV 分数；
去除 2,436 条 BEV 样本后，剩余 121,870 条样本的总体正确率为 **42.1%**。

SPAR 金标解析覆盖 54,488 / 54,495 条，为 **99.99%**。
无法无歧义解析的 7 条金标不进入对应分组的可评分分母。

### 6.3 分数据集的可信度证据

| 数据集 / 评测集 | 可信度检查 | 结果 | 解读 |
|---|---|---|---|
| `llava_hound_64k` | 语义校准：100 条确定正例 + 100 条错配负例 | 正例 0 漏判；负例 1 误接受 | 语义分支可用，但存在约 1% 的校准负例误接受 |
| `sweep_vlm3r` | 规则已判样本反向交给 LLM 提取 | 2/391 分歧，0.51% | 选择题/数值规则与 LLM 提取高度一致 |
| `sweep_spar32` | 规则已判样本反向交给 LLM 提取 | 10/305 分歧，3.28%；大幅分歧 6/305，1.97% | 修复 `Frame-N` 数字误读后，系统性分歧显著下降 |
| 完整训练池 | 跨数据源综合反向抽查 | 12/386 分歧，3.11% | 人工复核 12 条后，均为规则符合原文、LLM 发生重答或补全 |
| `spar_3view`、`vsi_appr_order` | 未设置独立分层抽查 | 由完整训练池综合抽查覆盖 | 不能将 3.11% 进一步解释为这两个数据集各自的分歧率 |

反向抽查的含义是“规则评分与 LLM 提取后评分是否一致”，并不等同于规则错误率。
在完整训练池的 12 条分歧中，人工复核确认：部分选择题的回答末尾已明确给出字母，
但 LLM 重新解题后返回了其他选项；部分方向题中，LLM 补出了原回答没有明确表达的轴。
因此，这 3.11% 应视为两种判读路径的分歧上界，而不是规则层错误率。

### 6.4 LLM 补判是否系统性抬高得分

方向题中，LLM 补判样本的正确率为 8.1%，低于规则层可判样本的 12.2%；
在 `sweep_spar32` 中，对应结果为 3.7% 和 9.6%。
这符合预期：进入 LLM 分支的本就是表达更含糊、更难解析的回答。
现有结果未显示 LLM 补判系统性抬高总分。

## 七、评分工具修正与质量控制

评测过程中发现并修复了以下解析问题。修复前，这些问题均会低估 Teacher 得分：

| 编号 | 问题 | 影响范围 |
|---|---|---|
| T02 | 无法读取句末数字（如 `"...is 0."`） | VSI-Bench 数值题兜底解析 |
| T03 | 将物体编号误识别为测量值（如 `Object169`） | 3,007 条 SPAR 金标 |
| T06 | 将帧标签 `Frame-4` 误识别为数值 `-4` | `spar32` 数值题的 10.1%；完整训练池数值题的 1.25% |
| T07 | 金标侧使用独立宽松正则，将 `rj45` 中的 `45` 识别为答案 | 金标与回答解析口径不一致 |

其中，T06 对结果影响最大。Teacher 回答经常引用 `Frame-N`，原解析器会把连字符识别为负号。
修复后，`spar32` 数值题正确率由 24.7% 提升至 27.4%，反向抽查分歧率由 8.6% 降至 3.3%。

所有可解析的结构化金标均通过“**将金标作为模型回答时必须获得满分**”的自洽测试；
金标侧与回答侧现已复用同一数字解析定义，以避免口径再次分叉。

## 八、结论与决策建议

### 8.1 实验结论

1. **Teacher 不是统一可靠的监督源。** 总体正确率约 41%，且可靠性强烈依赖数据源和题型。
2. **高视角预算不能弥补推理与回答协议缺陷。** 视角增加有效，但边际收益快速下降。
3. **空间想象题的核心问题是输出完整性。** Teacher 已输出轴的判断并不差，但经常没有答全。
4. **Teacher 回答风格本身是训练风险。** 长篇分析可能通过整段 response 蒸馏传递给 Student。
5. **后续训练应从统一蒸馏转向质量感知蒸馏。** 数据选择、题型权重与回答格式需要联合设计。

### 8.2 采用“8 视角基础预算 + 按需补充”的策略

两条受控扫描均显示边际收益递减：`vlm3r` 在 5 视角后趋于饱和，
`spar32` 在 16 视角后增益明显趋缓。综合监督质量与计算成本，建议将 8 个视角设为基础预算，
并根据题面中的显式帧引用补充必要视角，而不是对所有样本固定使用 32 个视角。
需要说明的是，`spar32` 受控扫描仅包含不引用特定帧的题目；
因此，当前证据不支持把所有 32 视角样本无条件截断为 8 个视角。

### 8.3 暂缓直接蒸馏 `spatial_imagination_oo_*`

该类共 5,730 条样本，严格正确率仅为 1.3%–1.5%。
建议先修改 Teacher 提示词，明确要求分别输出水平、垂直和深度三个空间轴，并使用本评测流程复测。
若正确率仍未达到可接受水平，再将其排除或降低蒸馏权重。

### 8.4 按题型可靠性设置蒸馏权重

不同题型正确率相差 40 倍以上，不应使用统一权重。
可优先使用 `llava_hound` 描述题、`spar_3view` 距离推断题和
`vsi_appr_order` 排序题；三类合计 44,229 条，正确率为 55%–58%。
低可靠性题型应降低权重，或在改进 Teacher 输出协议后重新评估。

### 8.5 建议增加短答约束消融

在调整大规模训练池前，建议先比较：

```text
原 Teacher prompt
vs
明确要求“只输出最终答案”的 Teacher prompt
```

重点观察 Teacher response median、截断率、VOPD token 构成及 Student 的 VSI-Bench 曲线。
该消融用于判断监督错误和回答风格分别贡献了多少退化。
